# 📊 Smart Grade Analysis System

A web-based **Smart Grade Analysis System** designed to simplify the analysis of student academic performance. The system allows users to upload grade data and quickly obtain meaningful insights through automated analysis and visual representations.

## 🚀 Live Demo

**Coming Soon** — The application will be deployed on Vercel.

## 📌 About the Project

The Smart Grade Analysis System helps students, teachers, and academic institutions analyze student grade data efficiently.

Instead of manually calculating and organizing grades, users can upload their academic data and get an automated analysis of the results.

## ✨ Features

* 📁 Upload student data
* 📊 Analyze academic performance
* 📝 Support for **Excel, CSV, and PDF** files
* 🎓 Subject-wise grade analysis
* 📈 Grade distribution and statistics
* 🔢 Automatic calculation of performance metrics
* 📋 Organized and easy-to-understand results
* 💻 Simple and user-friendly interface
* ⚡ Fast data processing

## 🛠️ Technologies Used

* **React** – Frontend development
* **TypeScript** – Type-safe programming
* **Vite** – Development and build tool
* **Node.js** – Backend/runtime environment
* **Gemini API** – AI-powered functionality
* **HTML5 & CSS3** – Structure and styling
* **Git & GitHub** – Version control and project management

## 📂 Supported File Formats

The system is designed to work with:

* `.xlsx` — Microsoft Excel
* `.xls` — Microsoft Excel
* `.csv` — Comma-Separated Values
* `.pdf` — PDF documents

## ⚙️ How It Works

1. **Upload Data**

   * Upload an Excel, CSV, or PDF file containing student grade information.

2. **Process Data**

   * The system reads and processes the uploaded academic data.

3. **Analyze Grades**

   * Student performance and subject-wise grades are analyzed automatically.

4. **View Results**

   * The analyzed information is presented in an organized and easy-to-understand format.

5. **Understand Performance**

   * Use the generated statistics and grade distribution to identify academic performance patterns.

## 💻 Run the Project Locally

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### 1. Clone the Repository

```bash
git clone https://github.com/banushka315-ux/smart-grade-analysis-system.git
```

### 2. Open the Project

```bash
cd smart-grade-analysis-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the project root and add your required API key:

```env
GEMINI_API_KEY=your_api_key_here
```

**Never upload your actual API key to GitHub.**

### 5. Start the Development Server

```bash
npm run dev
```

The application will then be available on the local development server shown in your terminal.
